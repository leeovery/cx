TASK: theming-system-8-1 — Assemble The §9.4 Union Behind The ThemeEnumerator Seam (tick-71405e)

ACCEPTANCE CRITERIA (from the plan task):
1. A persisted `"theme": "tokyo-night"` against a directory with no such file yields one row — the built-in's — and no `not found` row.
2. A persisted slug naming an existing-but-invalid file yields one row: that file's, carrying its reason.
3. A `nord.theme` drop-in beside the `nord` built-in yields two rows (built-in valid + file `reserved name`), the only two-rows-for-one-slug input.
4. A persisted slug resolving to neither yields one unselectable `not found` row; the same slug under an unusable directory yields `unreadable`.
5. A persisted string failing the charset check yields one row with reason `bad name`, `Slug` empty, `Persisted` set.
6. Under a constant the two slot keys contribute nothing; under a pair each non-empty slot contributes and two slots naming the same missing slug collapse to one row.
7. An absent directory yields built-ins only, zero rejections, no `directory unusable` record; an unusable one yields built-ins plus persisted rows with `Union.DirUnusable` true and the condition absent from `Rows`.
8. `Count == len(Rows)`; `Rejected` counts exactly the rows with a non-nil `Rejection`; `theme: enumerated` carries those two values and no other attr.
9. `Open` emits exactly one `theme: enumerated`; five opens over the same broken directory emit five `enumerated` lines but one `theme: rejected` per distinct slug+reason.
10. `Reassemble` performs no file or directory access and emits nothing.
11. Built-in rows carry nothing distinguishing them from a valid drop-in other than `Source`.
12. A `Loader` constructed with `log.Discard()` produces zero records for any sequence of `Open` calls.

STATUS: complete

SPEC CONTEXT:
§9.4 (specification.md:1059-1072) defines the list as files ∪ built-ins ∪ persisted slugs resolving to neither, keyed on "resolves" not "has a file", with "one slug is one row, always"; a persisted slug resolving to nothing gets its own unselectable `not found` row; a charset-rejected persisted string gets `bad name`, never `not found`; the rule applies per-slot under an adaptive pair. §9.5 (1074-1092) makes built-in and drop-in rows deliberately indistinguishable, labels `bad name`/`reserved name` rows by filename while sorting `reserved name` by slug, and puts the `⚠ dir unreadable` row outside the ordering entirely as viewport chrome. §5.5 (384) pins `unreadable` over `not found` for a theme made unreachable by an unusable directory. §12.3 (1486) makes `theme: enumerated` a per-open INFO with `count` = rows produced (built-ins included) and `rejected` = unselectable rows, firing on absent and unusable directories alike. §13.3 (1623) requires the seam to return the finished union — never a directory listing — with assembly owned by `internal/theme` so `internal/tui` never becomes a fourth emitter of the `theme` component.
