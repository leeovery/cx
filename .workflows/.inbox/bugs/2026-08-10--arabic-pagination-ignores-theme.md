# Arabic paginator renders a hardcoded grey that ignores the active theme

`bubbles/list` escalates its paginator by itself: when the dot row grows wider than the list, `paginationView` (`bubbles/v2@v2.1.0/list/list.go:1187-1192`) switches the type to Arabic and renders `Styles.ArabicPagination` — a style assigned once at `list.New` via `DefaultStyles` with a hardcoded `#5C5C5C`, and never re-pointed by `applyCanvasMode` / `applyProjectCanvasMode`. Every other list-owned style follows the active theme through the restyle path; this one keeps bubbles' grey whatever theme is applied, and its exemption in the restyle residue record claims the numeric paginator cannot render because both lists run the Dots paginator — untrue, since bubbles swaps the type itself when width forces it.

Empirically driven, not hypothetical: a model with 200 sessions at `SetSize(40, 6)` renders `1/100` in `\x1b[38;2;92;92;92m` — the stale grey — after a full swap to the light theme. Reach is narrow but real: it needs page count to exceed the list width, i.e. a short or narrow pane (tmux split, small window) holding many sessions — and that shape of terminal is exactly where pagination is most active.

Provenance: found by the reviewer in the phase-4 effort-comparison replay (worktree experiment, 2026-08-09). The original phase-4 review saw the same exemption, judged it "practically unreachable", and passed it as a non-blocking note — so mainline carries both the un-themed style and the overstated residue wording to this day. The replay branch fixed it there; that branch is throwaway, so the fix needs landing on main in its own right.

The fix is small and fully specified: re-point `Styles.ArabicPagination` inside `canvasPaginationDots` (`Foreground(th.TextFaint.Color()).Background(canvas)` — same row the dots occupy, so the dot helpers are its natural home) with the `UnsetForeground().UnsetBackground()` counterpart in `colourlessPaginationDots`; correct the residue-block entry; add one assertion to `TestRestylePath_RepointsListOwnedStyles` in the same shape as the dot assertions (`Styles.ArabicPagination.Render("1/9")` carries the new theme's `TextFaint` SGR and not the old one).
